# libPSU plugins

Reusable building blocks composed by paper protocols.

| Directory | Maven artifact | Role |
|-----------|----------------|------|
| `cot-union/` | `mpc4j-psu-plugin-cot` | COT + PRG XOR union delivery |
| `mqrpmt/` | `mpc4j-psu-plugin-mqrpmt` | PKC:GMRSS21-style mqRPMT membership |
| `ccpsi/` | `mpc4j-psu-plugin-ccpsi` | Circuit PSI (ASIACCS:CSSW25 backend) |
| `aon-output/` | `libpsu-plugin-aon-output` | Aggregator → COT union plugin |
